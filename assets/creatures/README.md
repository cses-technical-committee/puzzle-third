# Technova Mascot Assets

This directory can hold custom image files for your event's mascot.
If no custom images are placed here, the game automatically uses the built-in animated vector SVG companion ("Nova").

## Supported Custom Artwork:
- `creature-idle.png` (Default state on Entry Screen and Map)
- `creature-thinking.png` (State during question solving)
- `creature-success.png` (State upon level completion)
- `creature-celebration.png` (State upon Vault victory)
- `creature-confused.png` (State upon incorrect answers)

### Recommended Format:
- Transparent PNG or WebP
- 512x512 pixels square
- High contrast against dark (#0B0F1E) backgrounds
